# MITCal

> MITCal keeps named inputs and component design sheets on one desk so a shaft, spring, or beam check can be read without starting from a blank page.

---

## Four Beats

1. **Name the job.** Title the MITCal sheet before you enter loads.
2. **Pin the live set.** Keep this part on the board and leave other sheets aside.
3. **Check once.** Read units before you change a diameter or length.
4. **Close the loop.** Leave a note so the next visit does not start from a blank page.

## First Questions

**Does MITCal replace every other program?**  
No. MITCal sits beside CAD and the files you already use.

**Can two people share one computer?**  
Yes. Each person keeps a separate MITCal sheet.

**Will a long part list stay readable?**  
Yes, if only one part stays on the live sheet.

**What should a new user try first?**  
One short shaft or spring check today, then the same sheet tomorrow.

**Can a beam sit with a shaft?**  
Better as two titled sheets than as one mixed file.

## Who Sits Down at MITCal

- **Study** — a small part is enough for a first pass.
- **Shop check** — named inputs stay with the formula.
- **Client note** — the component design sheet is easy to show.
- **Shared desk** — each file keeps its own part.
- **Handoff** — the next person reads which sheet to open.
- **Archive** — finished parts stay out of the live set.

## Field Note

MITCal is easier to trust when the sheet stays smaller than the folder of old parts. Name the part, keep the live inputs, and write which formula still matters. That record is short: not every calculator in the suite, only the path back to this check.

The same pass fits a class hour or a short shop review. Open the last sheet, finish one visible check, and leave fewer loose notes than you found.

## One Real Pass

Pick a part that already has a name. Open it in MITCal, keep only those inputs, and finish one visible check. Extra parts wait for their own title.

If the sheet feels crowded, drop anything that belongs to a different job. The next pass can have its own name.
